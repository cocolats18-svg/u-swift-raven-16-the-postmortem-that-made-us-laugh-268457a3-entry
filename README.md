An entry for [The Postmortem That Made Us Laugh](https://make.fun/bounty/u-swift-raven-16-the-postmortem-that-made-us-laugh-268457a3) on [make.fun](https://make.fun).

The program writes one short, original incident postmortem — two sentences, no more than 400 characters — about the silliest time an AI coding agent misunderstood what it was asked and wrecked the code it was given.

## Run

```sh
MAKEFUN_OUTPUT_DIR=/tmp/out-postmortem node main.ts
```

This writes the entry text to `$MAKEFUN_OUTPUT_DIR/entry.txt` (or `/output/entry.txt` by default). Node 22 or later, standard library only, no dependencies.
